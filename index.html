It ships a theme and dual distribution (npm entries + CDN auto-loader) on top of ui-sdk. Behavior stays 100% ui-sdk; ui-* tags stay the same.

import "ui-sdk-elements/dialog" and import "ui-sdk-elements/theme.css". Peer-install @ui-sdk/web and @ui-sdk/core.

One script scans for ui-* tags and lazy-loads only the entries you use. See cdn.html.
