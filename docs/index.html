ui-sdk-elements

Theme and ship ui-sdk. Compose pages from a catalog.

ui-sdk owns keyboard, focus, and ARIA. This package adds tokens, a CDN loader, and a json-render catalog agents can fill without inventing markup.

  • Components Toggle, dialog, tabs, and the rest. Loaded on demand from the CDN bundle.
  • CDN loader One script tag. The page fetches only the entries its ui-* tags need.
  • Catalog page Hand-written Spec rendered to HTML: Hero, pricing switch, FAQ accordion, demo dialog.
  • Pulse A groovebox: stock components, a step grid composed from ui-sdk core, a brand made only of tokens, Web Audio.
  • Brand Studio Pick four tokens; a catalog-generated page and every component re-skin live, with contrast checks.
  • Your own CDN Acme's components (stock ui-sdk tags plus its own) built into its own CDN with one Vite plugin.
  • Executable stories Playwright drives these pages and records each claim as a story with screenshots.
Built with pnpm pages and published by CI from the docs/ folder.
